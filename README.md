## Description 
The clients for the Draw It or Lose It game consists of the users who will participate in the game and any stakeholders involved in the project. One of the main requirements outlined for the game is accessibility across multiple web browsers, with a consistent user experience across different devices and operating systems. Other requirments include supporting one or more teams consisting of multple players, an associated stock image library thats configured to support concurrent requests across different clients, game-state management such as teams, players, images, and guesses between rounds, and only one instance of the GameService class in memory at any given time.
